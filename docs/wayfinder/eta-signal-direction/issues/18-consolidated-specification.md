# Consolidated Eta Signal specification

Type: task
Status: resolved
Blocked by: 17

## Question

Synthesize the resolved Wayfinder decisions into one implementation-ready
specification. The specification must define the public contract, private
invariants, package seams, Crux integration, executable gates, and migration
route without introducing a new design decision.

## Answer

The resolved decisions are consolidated in the
[Eta Signal V1 specification](../specification.md).

The specification defines the public algebra, atomic-pass model, scheduler,
topology, demand, observer delivery, package seams, stream bridge, diagnostics,
Crux integration, module ownership, gates, and implementation route.

It introduces no new design choice. The owning decision tickets remain the
source for rationale, evidence, rejected alternatives, and claim traceability.
