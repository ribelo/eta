Amendment to `journal.md` (which remains sealed/unedited). Records the

## Fixes applied

1. **`Eta_js.Spi` alias removed** (one-namespace restoration). The
   `module Spi = Eta.Spi` re-export left `lib/js/eta_js.ml{,i}`;
   `lib/js_stream/eta_js_stream.ml` now consumes `Eta.Spi.Expert` directly
   and declares `eta` (`lib/js_stream/dune`; `dune-project` depends;
   `eta_js_stream.opam` regenerated by dune). Law-registry side effect:
   `eta_js.mli` line shift re-anchored R116–R126 (−1, content-verified;
   R126's span column and its static-boundary reference both moved).
2. **SPI eligibility doc broadened to its real consumers.** The bullet now
   reads "justified Eta library and package implementation support —
   runtime backends, backend-aware leaves, and runtime-owned infrastructure
   such as lifecycle protocols, eviction loops, and protocol readers",
   covering the in-repo consumers (`eta_cache`, `eta_signal`, `eta_http`,
   `eta_stream`, protocol clients, `eta_blocking`, `eta_otel`). The other
   three sentences (not application API / no compatibility guarantee / not
   for dependency injection) are verbatim. Registry: R41/R42 and CD-E22-018
   re-anchored +2 (content-verified).
3. **Example assertion matches its demonstration.** The
   `"worker completed after scope exit"` assertion moved inside the
   `with_background` body immediately after the explicit `done_` await and
   relabelled `"worker completed before scope exit"` — the ordering the
   example exists to teach. Running the example for this fix exposed a
   latent original-batch defect: it never compiled (`Eio.Promise.resolve`
   given the promise, not the resolver) because the four mandated gates
   do not build `@examples`. Fixed; `@examples` builds and the example
   runs green (`started=true before=false after=true`).
